# 项目素材与分镜智能体

素材制作保留两个工作入口：项目素材、分镜智能体。创意方案负责文案，镜头讨论和成图集中在素材制作；旧版分镜图片和动态预演也会进入素材网格，原版确认和渲染控制留在折叠资料区。

## 分镜生成

选择文案来源（优先最近已确认稿，未确认稿可用于测试）→ 本机 Codex / 对话 MCP 根据上下文提出三轮问题，每轮至少三个方向 → 整理镜头表 → 核对统一风格、画幅、每镜动作和提示词 → 点击生成。每批 1–8 镜，按已确认方案逐镜生成；首镜供本机 Codex 后续镜头参考。来源稿号、文字摘要哈希、镜头表、服务与生成图片均保存到该项目。

文案对话和分镜对话分别存储。更换来源后发送修改要求会重新开始方向讨论，不把原文案选择当成新稿已确认。旧镜头表保留原来源；新稿出现时旧图提示核对。图片生成不自动标记验收通过，也不自动推进制作阶段。

每镜完成后立即保存并展示。部分失败保留已成功镜头；用户点击「继续未完成镜头」只补缺失的镜头。请求 ID 防止同一批提交重复创建；服务中断标记为中断，不自动重试远端调用。远端超时不能证明它没有生成或计费，继续前应核对服务结果。

本机 Codex 调用现有登录状态，实际推理和出图使用在线账号额度；不把本机执行误称离线生成。MCP 出图服务和对话服务分开配置。

## MCP 扩展边界

目前支持 Streamable HTTP 的工具发现和调用：选择提示词字符串字段，其他必填参数填写固定 JSON。出图工具需同步返回恰好一条标准 MCP `image` content（PNG/JPEG/WebP，最大 20 MB）；图片字节落到本机。仅返回 URL、任务 ID 或需要异步轮询的 TapNow/LibTV 等具体服务需增加专用适配，不将一般对话工具当作出图服务。当前没有声称已连接这两家真实服务。

通用 MCP 传递文字风格和镜头提示词；尚无通用参考图字段映射。认证只配置 `MAMBA_MCP_` 前缀环境变量名称，密钥不进入页面或仓库。重启工作台使环境变化生效。

## 本地导入、分类与播放

文件选择器支持 PNG/JPEG/WebP/GIF 和常见视频、音频。流式复制到项目数据目录，每文件最多 512 MB，原文件保留；同项目按内容哈希去重。较大视频使用工具素材库按原目录索引，不强制复制。失败文件保留重试入口，已成功的文件不重复导入。

可按来源、分类（分镜图/实拍素材/参考素材/声音/其他）、图片/视频/音频及审核状态筛选。单项可修改分类、镜号与状态。点击视频进入大屏播放器，提供全屏、保存文件、关闭返回；关闭时停止播放器。工具素材库的视频使用同一播放器，原格式不能播放时尝试兼容预览。

数据在本机 `data/project-materials`，分镜对话在 `data/material-chat`，旧分镜在 `data/storyboards`。浏览器的 JSON 项目备份不含这些媒体和分镜对话，应随本机数据目录一起备份。配置、媒体、客户文案和运行记录不进入 Git。

## 验证

`test-production-materials.mjs` 覆盖三轮问答、来源切换、部分失败/补图、重复请求、首镜参考、导入去重、签名与 Origin 校验、范围播放、元数据版本冲突、重启和项目隔离，以及模拟 MCP 服务的真实协议交互。真实本机 Codex 使用合成几何场景验收镜头表及单帧出图，不发送客户资料。
