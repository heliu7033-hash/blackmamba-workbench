# 项目卡片首页与制作树

首页只展示项目卡片和原有新建项目入口。所有项目均有卡片，包含已归档项目；进行中优先，已归档排在最后。卡片叠加项目名、当前阶段编号、阶段名称和项目状态，整张卡片可用鼠标或键盘进入对应项目的工作流。

封面优先使用项目本机预览，其次使用已有项目概念图；缺少图像时显示按项目名称绘制的二维示意并标注来源。项目根节点提供「更换封面」，可选图片或视频生成缩略图，源媒体不移动，旧预览保留在项目内。

工作流顶部为当前项目根节点，下方按 01–04 展开创意方案、素材制作、剪辑后期、交付归档。阶段编号表示制作顺序，分支不是自动并行执行的任务。当前阶段高亮，各分支提供：

- 点击阶段标题进入唯一的主要工作区。
- 每个分支直接展示最新成果及状态：文案稿次、制作素材、剪辑版本、交付记录。
- 旧稿和其他成果按需展开；树中不再重复展示任务、验收清单和工作区入口。

阶段页面以主要操作和最新成果为主；简报、分镜与预演、视觉参考、旧补充记录、任务和验收参考集中在「参考资料与项目管理」中。素材只保留一个登记入口；剪辑、画面和声音通过同一个版本表单选择。所有已有记录保留，不做删除或自动验收。

进入下一阶段不自动勾选前序清单。仅有工作记录或已完成的单个任务不等于整个阶段已验收。项目树展示阶段状态与成果状态，任务和验收详情收在管理区；不猜测后台智能体正在运行。

宽屏采用顶部根节点、四列阶段及下属分支；窄窗口改成带连线的纵向树，保留阶段顺序，不压缩成难以阅读的四列。

验证使用隔离浏览器存储及临时任务数据；`scripts/test-project-tree.mjs` 覆盖全部项目入口、归档项目、阶段跳转、在办/待确认/缺失任务状态、验收区分、空状态与只读渲染。
