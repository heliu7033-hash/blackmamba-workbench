# 本地素材库与达芬奇导入

入口：点击工具默认打开素材库，素材库位于分区第一项（`#media`）。左侧以导入文件夹原名显示可展开的目录菜单，保留子目录层级。点击目录名称，筛选该目录及子目录中的素材；关键词和类型筛选叠加在此范围内。「全部素材」恢复跨目录检索。目录旁显示素材数量，不改变磁盘文件位置。

鼠标停留卡片约 280 毫秒后，视频在卡片内播放，音频直接试听；移开即停止并释放播放器，同一时间只播放一项。点击视频卡片进入大屏播放器，可全屏播放、保存文件或关闭返回；素材仍被选中，可继续设置达芬奇导入目标。上方「悬停预览声音」可切换静音，原生 App 支持无点击悬停试听；普通浏览器若限制自动出声，点击卡片后启用试听。切换页面、窗口失焦或页面隐藏时停止悬停播放。

浏览器不支持的格式自动尝试生成最多前 12 秒的兼容预览；详细面板的完整预览和达芬奇原素材导入仍保留。每页 36 项。

首次打开时仅读取一库 `config.json` 的 `roots` 字段，保存为工作台自己的 `data/media-library.json`。之后只使用工作台配置，不启动、不调用、不修改一库。可以在「管理素材文件夹」中独立增删目录。索引存入 `data/media-index.sqlite`，预览缓存存入 `data/media-previews`；素材原件不复制、不修改、不上传。索引完成后需要「重新扫描」更新新增或移动的文件。离线目录保留索引并提示，重新连接磁盘后重新扫描。

达芬奇需运行并打开工程与时间线，偏好设置的外部脚本使用须允许本地连接。工作台通过官方本机 Python 脚本 API 连接。界面显示目标工程、时间线、播放头、轨道，支持时间线末尾或当前播放头的空闲位置。视频可导入画面及原声或仅画面，音画片段会尝试链接；纯音频导入所选音轨；图片默认 5 秒。导入完成后在达芬奇保存工程。

导入前核验工程与时间线 ID、轨道存在和锁定状态，并拒绝覆盖目标轨道已有片段。切换工程或时间线后要刷新目标。文件可能已进入媒体池，但碰撞检查失败时不会写入时间线。导入结果回显实际轨道和帧范围。同一请求不会重复执行，超时或部分返回时锁定新导入；手动检查时间线后使用「检查未确认的导入」解除锁定。锁定跨服务重启保留。

## 本机依赖与范围

- Node.js 24+；macOS 的 Python 3 及 DaVinci Resolve 官方 Scripting 模块。
- 缩略图及兼容预览使用本机 `ffmpeg`：依次查找 `MAMBA_FFMPEG`、`~/.local/bin`、Homebrew、`/usr/local/bin`、`/usr/bin`。同时最多生成两份预览，单次最长 180 秒；原始预览及原文件导入不依赖转码成功。
- 支持常见 WAV/MP3/AAC/M4A/AIFF/FLAC/OGG、MP4/MOV/MKV/MXF/AVI、JPG/PNG/WEBP/TIFF/HEIC 等扩展名。具体解码能力取决于浏览器、ffmpeg 和达芬奇。
- 检索是文件名与路径检索，不包含语义检索、自动翻译或素材内容分析。目录管理填写完整路径；不扫描隐藏目录和符号链接子目录。
- `media-library.mjs` 提供本地 API，`scripts/resolve-media.py` 负责达芬奇桥接，`web/media-library.*` 为页面。桌面打包包含这些文件，云端不提供本地素材接口。
- 所有请求沿用本地服务 Host/Origin/Sec-Fetch-Site 限制；播放接口只接受索引内 ID，并再次检查文件位于已登记目录内；支持 Range 播放与拖动。

## 音频卡片波形

音频卡片显示完整素材的真实振幅包络与时长。可见卡片按需加载，客户端和解码服务均最多同时处理两个波形；离开结果页会丢弃尚未开始的工作。FFmpeg 以流式 PCM 读取音频，保留原采样率与各声道绝对峰值避免反相抵消，将其归并为 128 段并按每条素材峰值归一化；波形展示结构，不用于跨素材比较响度。静音素材显示平线。

结果缓存于 `media-previews/*.wave.json`，按素材 ID、文件大小、修改时间和算法版本复用。原素材不被改写；文件变化会重新生成。失败显示“波形暂不可用”，不影响试听与导入。仍支持卡片内悬停试听。

验证：真实合成 WAV（静音、不同幅度段、双声道反相），缓存复用与修改失效、并发合并、非音频及损坏文件处理；使用隔离素材索引进行浏览器与正式 App 外观验收。

## 中文显示名称

`data/media-names.zh.json` 是本机名称对照表，结构为 `{version:1,entries:[{id,original,display}]}`。服务启动时校验并导入独立的 `media_names` 表。匹配素材 ID 和原文件名后才显示中文别名，重扫不会覆盖翻译；未匹配素材显示原名。损坏的名称表保留上次有效结果并提示。

卡片标题和详情显示中文，卡片下方保留英文原名，完整路径可在提示和详情查看。检索同时匹配中文名与原路径；文件播放、波形缓存和达芬奇导入仍使用原 ID、原路径。名称对照表属于用户本机资料，不纳入 Git，翻译模型也不随 App 分发。新增素材没有对照条目时保留原名。
