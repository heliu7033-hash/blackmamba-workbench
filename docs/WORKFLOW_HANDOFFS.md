# 工作流交接

各阶段保留自己的成果和接收记录，下游可以看正文、播放文件和追溯来源。交接不等于客户验收，不会自动调用 Codex、达芬奇或 AE 执行工作。

- 创意方案：文案详情提供「确认并交给素材制作」。第一份已确认稿自动建立接收快照，历史已确认稿首次打开时也会补建。新稿出现不覆盖正在使用的稿件，素材页提示接收新版。
- 素材制作：顶部直接展示已接收文案正文。分镜使用这份正文；来源变化后，旧镜头表禁止继续按新来源出图，操作者点击重新讨论后重新经过三轮问答。
- 素材交给剪辑：将文件标记为已确认，勾选本次使用的文件，点击「交给剪辑后期」。工作台建立有编号的素材批次，记录文案快照、文件 ID、类型、摘要和镜号；重复交接同一批内容不重复创建。
- 剪辑后期：顶部显示已接收批次，可查看/播放/保存文件和下载交接清单。接收达芬奇导出时选择实际使用的批次。第一份已确认达芬奇底片自动出现在 AE 接收区，新底片须明确接收，已有包装稿不会改绑。
- AE 与交付：AE 版本继承选定达芬奇版本的素材与文案来源；转入交付后保留完整来源链，可从成片追溯正文和文件清单。旧版本缺少关联时明确标注，不推测其来源。

接收快照位于项目记录 `workflowHandoffs`：`copies` / `activeCopyId` 为文案历史和当前接收稿，`materials` 为素材批次，`aeInput` 为当前包装底片。新后期记录通过 `materialPackage` 和 `upstream` 追溯。文件继续使用本机项目素材目录或旧分镜文件，不复制到 JSON 备份。复制或恢复项目时应同时备份媒体目录。

版本审核状态可变，但正文、文件内容和来源关联不会因上游出现新稿而自动替换。撤回文案确认后，素材交接会要求重新核对。不同项目的交接数据独立。
