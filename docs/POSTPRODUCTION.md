# 达芬奇、AE 与交付版本

剪辑后期保留两个主要入口：达芬奇剪辑调色版本、AE 包装版本。工作台先接收软件正常导出的文件，不启动或控制软件渲染。

1. 在达芬奇完成剪辑、调色和声音处理，导出视频，在工作台点击「接收达芬奇导出」。文件复制到本机项目目录，产生独立编号的待复核版本。
2. 大屏播放并检查，在「版本详情 / 审核」更新状态与时间码反馈。可以同时记录 `.drp` 或可编辑工程的位置。
3. 使用「保存底片供 AE 使用」取得底片，在 AE 完成包装。接收 AE 导出时选择它实际使用的达芬奇版本，可登记 `.aep` 工程位置。两类版本分别递增；旧 AE 不会因新达芬奇稿出现而被改绑。
4. 将成片标记为已确认后，点击「转入交付归档」建立待交付记录。无需包装时可以直接选择已确认的达芬奇版本。交付记录保留来源版本，可继续记录客户反馈、验收状态与归档位置；不自动完成项目验收清单或把项目标为已归档。

历史版本保留；新版本记录的媒体与来源关联不可覆盖，审核状态和反馈可更新。原有粗剪、精剪、声音记录保留在折叠区，不猜测它们对应的软件或底片。

视频文件支持 MP4、MOV、WebM、MKV，单文件最大 20 GB，按流写入，不读取整段视频到服务端内存。接收会占用一份本机磁盘空间，原始文件不变。编码是否可在工作台播放取决于浏览器支持；MP4/H.264 便于预览，不能解码的文件可保存到本机查看。20 GB 为配置上限，本次验收使用小型合成 MP4，没有进行 20 GB 文件压力测试。

文件位于 `data/project-materials/<project hash>/files`。后期用途与原始项目素材分开展示，同一用途同内容去重，跨达芬奇/AE 用途保留各自引用。工作台导出的 JSON 备份不包含视频和工程，恢复时须同时备份项目文件目录与原始工程。记录“已验收”不代表已自动复制到外置归档盘。
