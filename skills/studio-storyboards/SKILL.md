description: 从黑曼巴工作台当前项目的创意方案生成可调整的多镜头分镜，确认静帧版本后用本机 Remotion 渲染对应动态分镜。
---

在工作台选择项目，进入「素材制作」。新的「分镜智能体」先通过问答整理镜头表，核对后逐镜出图并进入项目素材。已有分镜和动态预演仍可在「参考资料与项目管理 → 旧版分镜与动态预演」中查看。

旧版流程：点击「生成分镜图」，核对即将发送给已登录 Codex 的方案摘录和镜头数。只有摘录及本版第一镜的参考静帧用于出图。使用独立验收项目测试新流程。

工作台调用本技能的 scripts/engine.mjs。它通过本机 Codex CLI 规划动作、时长和运镜，逐镜调用图像生成。生成中可离开阶段再回来查看；失败会列出原因。修改画面描述需要生成新版本。

预览各镜头，按需调整动作说明、时长和运镜，点击「确认此版本」。确认后同一版的镜号、静帧、时长与运镜锁定。点击该版的「生成动态分镜」使用 Remotion 输出无声 MP4；渲染只读取这版确认过的静帧。对照项目内版本号、镜头数、首尾画面和总时长验收。

桌面运行依赖本机已登录且支持内置图像生成的 Codex CLI、Node.js 24、同版本 Remotion 和 @remotion/cli、Chrome。工作台数据目录中的 storyboards 保存版本及媒体，随项目整理备份。可以在本机环境设置 MAMBA_CODEX_BIN、MAMBA_REMOTION_CLI 或 MAMBA_CHROME 指定安装位置。请勿把客户方案、成图或运行目录提交到代码仓库。
